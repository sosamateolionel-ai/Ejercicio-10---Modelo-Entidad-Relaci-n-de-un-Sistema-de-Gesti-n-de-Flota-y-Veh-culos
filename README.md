# Ejercicio-10---Modelo-Entidad-Relaci-n-de-un-Sistema-de-Gesti-n-de-Flota-y-Veh-culos
Este ejercicio consiste en diseñar un modelo Entidad-Relación (DER) para un sistema de gestión de flotas y transporte. El modelo permite administrar vehículos, choferes, viajes, asignación de personal, registro de cargas de combustible y control de mantenimientos en talleres.
